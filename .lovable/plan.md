# LSTM presentation walkthrough

## What to build
- Add an interactive LSTM explainer below the existing health chatbot.
- Let visitors choose sample wellness phrases and follow their words through conceptual LSTM stages: sequence input, gate/memory handling, and topic output.
- Show an illustrative topic result and clearly state that this is an educational walkthrough, not a trained or diagnostic model. Keep the current chatbot behavior unchanged.

## Technical approach
- Create a focused React component using existing design-system controls and semantic color tokens.
- Use fixed sample examples and explain the model visually without adding an ML dependency or claiming real inference.
- Verify with the project’s available tests and a browser check of the presentation flow.
